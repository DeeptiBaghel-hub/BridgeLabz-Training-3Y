Responsive CSS Cheat Sheet

Filters

CSS filters change the visual appearance of elements.

filter: grayscale(100%);

Media Queries

Media queries apply styles according to screen size.

@media (max-width: 700px)

Responsive Design

Responsive design makes layouts work on different devices.

width: 100%;

Typography

Relative units help text scale with the screen.

font-size: 2rem;
